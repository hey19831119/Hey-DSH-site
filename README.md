## 飞书使用说明

在飞书群中 @老何的DSH助手 并说明要完成的事情，机器人会把它登记为一项独立任务，完成后在原消息的回复中反馈结果。

- **发起任务**：@ 机器人后直接写需求，尽量说明目标文件和期望结果，例如：

  ```text
  @老何的DSH助手 请把 README 中的仓库结构说明补充完整，并开一个 PR
  ```

- **执行方式**：改动在仓库的独立 `agent/` 分支上进行，不会直接修改 `main`；涉及代码的改动通过 PR 提交。
- **结果反馈**：任务完成后机器人回复结果；涉及代码改动时会附上 PR 链接，PR 由人审核后合并。
- **继续沟通**：在机器人的回复下追加消息，可以补充需求或询问进度。
- **前提条件**：机器人需要先被拉入群聊，发送请求时请在消息中 @ 它。
